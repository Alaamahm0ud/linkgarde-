# 🔗 لينكغارد — تحليل الروابط الذكي وكشف التهديدات

إطار عمل متقدم لتحليل الروابط — يدمج الكشف متعدد الطبقات، المعالجة بالذكاء الاصطناعي، والتخزين المؤقت لضمان تقييم تهديدات سريع وموثوق.

## ⚙️ نظرة عامة

لينكغارد هو نظام حديث وعالي الأداء لتحليل الروابط، مصمم للكشف اللحظي عن التهديدات.  
يجمع بين التحليل القائم على القواعد، معالجة اللغة الطبيعية، المحاكاة البصرية، والصندوق الرمل الديناميكي في خط معالجة متكامل وغير متزامن.

## 🧠 القدرات الأساسية

- تحليل الروابط باستخدام القواعد (الكلمات المفتاحية، المجالات المشبوهة)  
- معالجة اللغة الطبيعية (DistilBERT) لاكتشاف التصيد الاحتيالي  
- تحليل بصري للصفحات (محاكاة الشعار والتخطيط للتحقق من المحتوى)  
- محاكاة ديناميكية لسلوك الصفحة (Dynamic Sandbox)  
- تحليل بصمة المهاجم (عمر الدومين، مسجل النطاق، التهديدات المعروفة)  
- تقييم التهديدات وتخزين النتائج في Redis للتكرار السريع  
- تنفيذ غير متزامن بالكامل ومتوازي لأداء عالي

## 🧠 مكونات النظام

### ⚙️ مُهيئ المكونات (Component Initializer)

يقوم بتحميل نماذج الذكاء الاصطناعي الثقيلة (NLP وVision) وإنشاء اتصال Redis عند بدء تشغيل الخادم لتحسين الأداء.  
يتم تنفيذ الدالة `initialize()` عند حدث `startup_event` في FastAPI.

### 🔍 المحركات الصغيرة / وحدات التحليل

- **RuleEngine**: تحليل سريع للروابط باستخدام القواعد  
- **NLPProcessor**: استخدام DistilBERT للفهم الدلالي واكتشاف التصيد  
- **VisionAnalyzer**: محاكاة تخطيط الصفحة والشعار للكشف عن الاحتيال البصري  
- **DynamicSandbox**: محاكاة تحميل الصفحات ومراقبة السلوك  
- **AttackerFingerprinting**: تحليل بنية الدومين، عمره، المسجل، وتاريخ التهديدات

### 🧮 التجميع والتخزين

- **ThreatScoringService**: يجمع نتائج جميع المحركات، يطبق درجات الوزن، يصنف مستوى التهديد ويقترح توصيات  
- **ResultCache**: يتفاعل مع Redis لتخزين النتائج مؤقتًا، مما يقلل وقت الحساب للطلبات المتكررة

### 🤖 SmartLinkDetectorPro

يقوم بتنسيق جميع المحركات لكل طلب تحليل.  
يتحقق أولًا من التخزين المؤقت، وإذا لم توجد نتيجة، يطلق المهام غير المتزامنة لكل خدمة باستخدام `asyncio.gather`.  
يجمع النتائج، يحسب درجة التهديد، يخزنها في التخزين المؤقت، ويعيد التقرير النهائي.

## 🌐 بوابة API

مصممة باستخدام FastAPI للأداء غير المتزامن.

**Endpoints:**

- `POST /analyze` — إرسال رابط للتحليل  
- `POST /feedback` — استقبال تصحيحات المحلل (حلقة تحسين ذاتي)  
- `GET /health` — فحص حالة الخدمة
