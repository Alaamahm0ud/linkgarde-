🔗 LINKGARDE — تحليل الروابط الذكي والكشف عن التهديدات

إطار حديث لتحليل الروابط، يجمع بين الطبقات المتعددة للكشف، الذكاء الاصطناعي، والتخزين المؤقت لتحقيق سرعة ودقة عالية.

⚙️ نظرة عامة

LINKGARDE هو نظام تحليل روابط عالي الأداء مصمم للكشف عن التهديدات في الوقت الفعلي.
يجمع بين التحليل القائم على القواعد، NLP، المحاكاة البصرية، و sandbox الديناميكي في خط معالجة موحد غير متزامن.

القدرات الأساسية

تحليل روابط سريع قائم على القواعد (الكلمات المفتاحية، النطاقات المشبوهة)

فهم دلالي باستخدام NLP لاكتشاف التصيد (DistilBERT)

تحليل بصري للصفحة (محاكاة الشعار والتصميم)

محاكاة sandbox ديناميكية لسلوك الصفحة

تحليل بصمة المهاجم (عمر النطاق، المسجل، التهديدات المعروفة)

تجميع النتائج وحساب درجة التهديد مع التخزين المؤقت في Redis

تنفيذ غير متزامن ومتوازي للأداء العالي

🧠 مكوّنات النظام
⚙️ Component Initializer

تحميل نماذج الذكاء الاصطناعي الثقيلة وإنشاء اتصال Redis عند بدء الخادم لتوفير الوقت والموارد.

🔍 الخدمات المصغرة / محركات التحليل

RuleEngine: تحليل روابط سريع قائم على القواعد

NLPProcessor: فهم دلالي للروابط باستخدام DistilBERT

VisionAnalyzer: تحليل بصري للصفحة للتحقق من التزوير

DynamicSandbox: محاكاة سلوك الصفحة بدون تنفيذ مباشر

AttackerFingerprinting: تحليل البنية التحتية للنطاق وتاريخها وربطها بالتهديدات

🧮 التجميع والتخزين

ThreatScoringService: دمج النتائج، تطبيق الأوزان، تحديد مستوى الخطر، وتقديم التوصيات

ResultCache: تخزين النتائج مؤقتًا في Redis لتقليل وقت التحليل عند إعادة الطلب

🤖 SmartLinkDetectorPro

تنسيق جميع خدمات التحليل، التحقق من التخزين المؤقت، تشغيل جميع المهام غير المتزامنة، وحساب درجة التهديد النهائية.

🌐 API Gateway

واجهة FastAPI مع نقاط نهاية:

POST /analyze لتحليل الرابط

POST /feedback لاستقبال التصحيحات

GET /health لفحص صحة الخدمة

🚀 التشغيل المحلي
uvicorn src.api_gateway:app --reload --host 0.0.0.0 --port 8000
curl -X POST http://localhost:8000/analyze -H "Content-Type: application/json" -d '{"url":"http://example.com"}'
